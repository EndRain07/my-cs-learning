## 环境配置/工具理解
- 关于java切换:
```
set "JAVA_HOME=C:\Program Files\(某版本地址))"
gradlew.bat dist
```
- jadx 克隆后用gradle
- jadx-ai-mcp 克隆后用Meven
- 关于jadx-ai-mcp:
```
   LLM Client
    |
    | MCP协议
    ↓
jadx-mcp-server
(Python)
    |
    | HTTP请求
    ↓
JADX-AI-MCP Plugin
(Java)
    |
    | HTTP请求处理
    ↓
JADX GUI
    |
    ↓
APK
```
- 安装uv
- 安装blutter
以后每次使用：
```
cd /d D:\retool\blutter
call .venv\Scripts\activate
```
- idalib安装IDA mcp
```
激活
uv run "D:(路径)\idalib\python\py-activate-idalib.py"
执行
uv tool install --python 3.12 git+https://github.com/mrexodia/ida-pro-mcp
```
- 安装完成后，将两个mcp工具都导入agent

## 后续通用操作
- 启动JADX
- 启动python mcp server
```
cd /d (路径)jadx-mcp-server
uv run jadx_mcp_server.py --http
```
- 用agent接入(以grok build为例)
```
grok mcp doctor jadx-ai-mcp
```
- 关闭顺序：先关闭MCP Server，再关闭JADX
- 启动IDA
- 一般会自动启动MCP插件，若无，crtl+alt+M，检查
```
netstat -ano | findstr :13337
```
- agent验证（grok biuld为例）
```
grok mcp doctor ida-pro-mcp
```
