- pnpm管理

安装前先查看 npm 当前目录：
```
npm prefix -g
npm root -g
npm config get cache
```
然后：
```
npm install -g pnpm@10

pnpm config set store-dir "pnpm-store路径" --global

where.exe pnpm
pnpm -v
pnpm store path
pnpm config get globalconfig
```
确认位置以后，再安装项目依赖：
```
cd "项目地址"
pnpm install --frozen-lockfile
```
这样不会出现依赖“乱飞”，记住四处：
```
pnpm 命令     → npm 的全局目录
公共包仓库   → D:\xx\retool\pnpm-store
项目依赖     → 项目\node_modules
编译产物     → 项目\dist
```
uni小程序启动：
```
pnpm dev:mp-xxxx
```
