# sstream 字符串输入输出流

## 常见类


### istringstream && ostringstream
- i最常见：读取同行的多个多位数：
```
std::string A;
std::getline(std::cin, A);

std::istringstream iss(A);

int x;
int ins = 0;

while (iss >> x) { //可以直接读取int类型
    a[ins++] = x;
}
```
- i读单词:
```
std::string line = "hello world cpp";

std::istringstream iss(line);

std::string word;

while (iss >> word) {
    std::cout << word << '\n';
}
```

- o拼复杂字符串
```
std::ostringstream oss;

oss << "第 " << 3 << " 个学生的成绩是 " << 98;

std::string s = oss.str();

//结果：第 3 个学生的成绩是 98
```

- o数字转字符串(可以配合iomanip)
```
#include <sstream>
#include <iomanip>

std::ostringstream oss;
oss << std::fixed << std::setprecision(2) << 3.1415926;

std::string s = oss.str();
```

| 语句                              | 含义                     |
| ------------------------------- | ---------------------- |
| `#include <sstream>`            | 使用字符串流需要的头文件           |
| `std::istringstream iss(line);` | 创建输入字符串流，从 `line` 里读数据 |
| `iss >> x;`                     | 从字符串流中读一个数据            |
| `while (iss >> x)`              | 不断读取，直到读不到为止           |
| `std::ostringstream oss;`       | 创建输出字符串流，用来拼字符串        |
| `oss << a << b;`                | 像 `cout` 一样往字符串流里写内容   |
| `oss.str()`                     | 取出最终拼好的字符串             |
| `std::stringstream ss;`         | 创建可读可写字符串流             |
| `ss.clear()`                    | 清除错误状态                 |
| `ss.str("")`                    | 清空字符串流内容               |

### stringstream
- 能读能写
```
std::stringstream ss;

ss << "123 456";

int a, b;
ss >> a >> b;
```
