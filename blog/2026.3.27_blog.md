# 从困惑于怎么开始，到在VS Code成功运行第一个 Python 文件——Step记录

最近一段时间，作为某底211的大一学生，经历完上学期C++的重拾，还有几周就将面对学校的数据结构的课程开课的时候，我终于开始在想，自己到底该怎么开始真正的代码学习。

我并不是完全没有接触过编程。小学起就接触过一点 C++，也曾经被选入校训打CSP，但很可惜因为各种原因并没有好好学着走，没有留下扎实的积累。现在到了大学阶段，准确来说是前两天，我在研究课表时候发现：如果只是围着课程要求走，而在代码能力上几乎不主动拓展，后面会很危险。

但比“会不会落后”更让我焦虑的，其实是另一件事——我一直缺少一个明确的起点，从家乡里考出来，带着0经验来到新的地方，即使我曾经接触过编程，我也不知道怎么着手”开始“。

今天我决定先不想那么远，只做像当年下载dev-c++的时候一样的事：用下载后就没开过的VS Code把 Python 学习环境搭起来，并真正跑通第一个HelloWorld文件。

## 今天做了什么

今天主要完成了下面几件事：
- 确定Windows 11的环境
- 安装了 Python 3.13.0
- 安装了 Git（安装选项全程截图给AI指导  XD）
- 在 工作盘建立了 CS-Learning 学习目录


```
python

cpp

blog

notes

projects

tools
```


- 在 VS Code 中打开工作区
- 成功运行了第一个 Python 文件 first_hello.py
- 搜罗了git常用指令&Markdown常用符号
- 成功在github创建第一个公开仓库，连接到本地总目录，成功创建Main支点并首次push到公开仓库中，完成README的编写
这些事情看起来都不大，但对我来说意义很明确：从“想开始的人”，变成了“已经开始的人”。

## 过程中弄明白的几个点
在这个过程中，我也弄清了一些之前模糊的地方。虽然应该都是些蠢问题，但我觉得这种第一丝的“清明”认知会成为某种起点

首先，VS Code 和VS一样只是编辑器，不是 Python 本体。真正运行 Python 代码，还是需要本机安装解释器。之前我对这一点其实没有完全分清。

其次，Git 的安装步骤虽然看起来有点多，但对初学者来说，大多数选项并不需要一开始就深究。让AI翻译一下，先把流程走通，比一上来就追求“全都懂”更重要。

然后，在听了很多遍之后，第一次自己体会了在线仓库的创建过程和Git的操作过程和结果

另外，我第一次尝试区分通过终端而不是Code Runner来查看输出结果。

还有一点是，真正把第一个文件跑起来之后，心理感受和“只是知道自己装好了环境”完全不一样。前者让我第一次觉得：这不是停留在想法里，而是真的可以开始了。

## 为什么想把这件事记下来
我想把今天记下来，不是因为环境搭建 本身有多复杂，而是因为对我来说，这一步很具体，也很关键。

我想很多时候，隐形焦虑并不是因为真的做了很多失败的尝试，而是因为一直停在“想开始、但不知道从哪里开始”的状态里。今天至少让我确认了一件事：哪怕只是装好环境、跑通一个 Hello World，也比一直停在原地强。

接下来准备怎么做

如果以后回头看，我希望还能记得：我是从这里开始的。
