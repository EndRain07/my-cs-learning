## 工具使用

### Docker 基础流程

1. 编写 `server.py`
2. 编写 `Dockerfile`
3. 构建镜像

```bash
docker build -t docker-flag-lab:latest .
```

4. 本地运行并注入测试 FLAG

```bash
docker run --rm --name docker-flag-lab-test -e "FLAG=flag{docker_dynamic_test}" -p 127.0.0.1:10001:9999 docker-flag-lab:latest
```

5. 登录镜像仓库

```bash
docker login gitea.bxs.team
```

6. 添加远程标签并上传

```bash
docker tag docker-flag-lab:latest gitea.bxs.team/test/docker-flag-lab:latest
docker push gitea.bxs.team/test/docker-flag-lab:latest
```

### BXS::CTF 配置

- 题目类型：动态容器
- 镜像：`gitea.bxs.team/test/docker-flag-lab:latest`
- 服务端口：`9999`
- FLAG 通过环境变量 `FLAG` 注入
- 创建测试容器后，通过 WSRX 将 `wss://...` 转为本地 TCP 端口
